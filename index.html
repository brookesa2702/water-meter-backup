Water Meter Backup

A personal tool that records water meter readings and backs up a CSV file to the owner's Google Drive.

The tool runs on a Raspberry Pi. It retrieves readings from the Tuya cloud, saves timestamped readings locally, and uses rclone to copy the CSV to Google Drive.

Google authorization allows the tool to create and update its own files in the owner's Drive. It uses the drive.file permission, which limits access to files created by or explicitly authorized for this app.

This website provides information about the tool. It does not display meter readings or offer a public sign-up service.
